# Indy Center Developer Portal

Source for `tech.flyindycenter.com`, the developer documentation site for the Indy-Center GitHub org. It's an Astro + Starlight static site aimed at the volunteers building and maintaining the facility's web services.

## Local development

```bash
npm install
npm run dev           # start the local dev server
npm run check         # type-check with astro check
npm run format:check  # verify formatting with prettier
npm run build          # produce the static site in dist/
npm test               # run vitest
```
