Planned work lives in the `DEV` project, "Tech Team", a team-managed Jira project on the org's Atlassian site. Ask a maintainer for access. The roadmap lives there too; this site publishes what's been decided, not what's planned.

- **Epics.** Quarterly goals or longer-tail goals.
- **Stories.** Work to be done to push a goal forward. They're as detailed as you want.
- **Subtasks.** Available when a story is worth breaking up.
