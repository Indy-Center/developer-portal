title: Branching
description: How changes reach main in Indy Center repositories — a feature branch, a pull request, one approval.

---

Work happens on a feature branch and reaches `main` through a pull request that needs one approval. CI runs on the pull request where the repository has it, and repositories with a deploy workflow deploy on merge. [First contribution](/start-here/first-contribution/) walks the whole path.

Branch names, commit message style, and how the pull request is merged are up to whoever's doing the work. The repositories are open source and the team is three or four volunteers; we'd rather enforce the few things that matter in [CI](/agreements/ci-checks/) than set rules for the rest.
